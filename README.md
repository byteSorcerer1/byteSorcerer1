- **Engineering Track Record:** Full lifecycle ownership (architecture, core development, native bridge engineering, CI/CD automation, store distribution, and monetization) of multiple consumer apps operating in production.
- **Core Specialization:** High-framerate React Native & Expo bare-workflow, native Swift (WidgetKit / SwiftUI) & Kotlin (Compose / Background Daemons), Python AI backends, and low-latency systems.

## Featured APIs & Desktop Utilities

#### [Turkish Profanity Filter API (TemizSöz)](https://rapidapi.com/aktasmeertcan/api/turkish-profanity-filter-toxicity-detection)
A high-throughput, AI-driven content moderation engine designed for complex Turkish NLP patterns, phonetic mutations, and masked slang (e.g., `a.p.t.a.l`).
- **Architecture:** Python, FastAPI, Vercel Serverless Edge, Multi-Class Toxicity Classification.
- **Status:** [Active on RapidAPI](https://rapidapi.com/aktasmeertcan/api/turkish-profanity-filter-toxicity-detection)

#### [Regular Tapper](https://github.com/byteSorcerer1/Regular-Tapper)
An ultra-low latency desktop automation and input simulation utility written for Windows.
- **Architecture:** C#, .NET, WPF, Win32 User32 SendInput Native APIs.
- **Status:** Open-Source on GitHub
